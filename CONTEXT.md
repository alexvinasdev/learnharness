# LearnHarness (Alex's fork)

An agent harness for learning, being adapted for universal domain learning (e.g. languages) with explicit scope definition, cheatsheets, and grindable deterministic exercises.

## Language

### Learning intent

**Objective**:
The free-text *why* behind learning a domain ("live in Switzerland"). One or more attach to a Scope and are all simultaneous: each weights every topic independently, and topic importance can be viewed and filtered per Objective. Never limits the Scope.
_Avoid_: Goal (reserved for a session's free-text goal in the original app)

**Scope**:
The persistent, exhaustive topic map of a learning domain: a hierarchy of topics (leaves are Cheatsheet-sized) plus Dependency Edges discovered while teaching. Each topic carries Importance per attached Objective and a learning state. A first-class artifact, separate from the knowledge graph. Teaching sessions walk it directly — there is no per-session plan.
_Avoid_: Curriculum, syllabus, plan (the original app's Plan Tree is removed in this fork)

**Importance**:
The tier an Objective assigns to a Scope topic: Essential / High / Medium / Low / Excluded. An Excluded topic stays in the tree (exhaustiveness is kept) but is filtered out of teaching and practice by default.

**Leaf**:
A Scope topic small enough that its material fits in one Cheatsheet — the stopping point of decomposition. Cheatsheets and exercises attach to leaves; interior topics exist to group and carry Importance.
_Avoid_: Unit, module

**Dependency Edge** (removed):
A Scope edge recording that learning one topic requires first holding another. Its only writer was the teacher during teaching — retired with teaching sessions (2026-02). Existing edges remain in scope files as data; nothing writes new ones.
_Avoid_: Prerequisite link

**Orphan**:
An exercise or cheatsheet whose Scope topic was pruned. Kept intact and flagged as unlinked; re-linkable or manually deletable. Pruning a topic never destroys progress data.

**Scope Session**:
A session kind whose guided top-down interview produces or updates the persistent Scope: the agent proposes each level of the tree and pre-fills Importances; the learner confirms, prunes, and adjusts before recursing into children. One of two session kinds (the other is the Class); old teach/practice chats remain readable as history.
_Avoid_: Scope wizard, onboarding

**Class**:
A chat session kind that walks Scope topics — leaf by leaf — teaching from each leaf's Cheatsheet and exercising from its pool. The Scope supplies the route; the Cheatsheet the material; the Class the pacing.
_Avoid_: Lesson (the Cheatsheet is the lesson artifact), Teaching Session (retired — different machinery: probe, plan tree, propositions)

**Cheatsheet**:
The schematized theory of a Scope leaf — one local file, AI-generated from model knowledge plus graph propositions linked to the topic. Regenerable on demand: per-leaf, or in bulk over the whole scope (the bulk queue). Never manually edited.
_Avoid_: Summary, notes, auto-on-taught (dead)

**Topic State**:
A Scope leaf's learning evidence, DERIVED — never stored — from the grind: the share of the leaf's pooled exercises that are Learned (leaf roll-up). Interior topics show the roll-up of their leaves. Since teaching/practice sessions were removed (fork simplification, 2026-02), no agent writes states.
_Avoid_: Mastery, progress, mastery score, taught/held/partial (dead vocabulary from the chat era)

### Pre-existing terms (from the original app)

**Proposition**:
A single true claim taught or imported; the atom of the knowledge graph.

**Reasoning Chain**:
An argument: premises that jointly entail a conclusion. The stored truth behind the graph's derived edges.

**Plan Tree** (removed):
The original app's session-scoped dependency tree a teacher authored between what is held and the session goal. REMOVED in this fork (ADR 0001) — the Scope replaces it everywhere; Free Sessions carry no map at all.
_Avoid_: reusing "plan" for anything the Scope now does

**Probe** (removed):
The pre-teaching measurement of where the learner's understanding ends, taken against Scope topics. RETIRED with teaching sessions (2026-02) — the grind now discovers what you hold (you fail exercises, you study the cheatsheet).

**Practice Session** (removed):
An agent-driven session posing generative problems on the fly. RETIRED (2026-02): the deterministic grind is the practice surface; free production lives on only in the transcripts of retired sessions.

**Exercise**:
A deterministic practice item of a universal type — flashcard, cloze, ordering, matching, spot-the-error, numeric — attached to a Scope leaf. Two origins: a reviewed batch, or spawned by a Class to target a struggle the pool doesn't cover (a spawned exercise joins the pool once answered; dismissed spawns are discarded). Generated by an agent before the attempt, never at it; graded without AI; every attempt recorded.
_Avoid_: Problem (reserved: generative practice — now retired history), question, AI-judged attempt

**Grind Log**:
The append-only record of attempts per exercise: timestamp + binary outcome (an exercise with several parts counts as correct only when fully correct). Learned, fail %, and Rusty derive from it — nothing is stored as state.

**Learned**:
An exercise whose last K attempts (default 3) were correct. The streak is the gate; the lifetime fail % never blocks Learned.

**Rusty**:
A Learned exercise unattempted for over D days (default 21). A priority flag, never a schedule: one correct attempt clears it; one failure resets to not Learned.

**Buried**:
An exercise excluded from selection by the user but kept, with history intact — nothing deletes grind data automatically.

**Grind Session**:
A non-chat view serving exercises from a chosen pool (whole Scope / subtree / objective filter) one at a time with instant binary feedback, until stopped. Selection is greedy at each pick — not learned, then rusty, then maintenance — with no AI in the loop.

**Free Session** (removed):
A session without a Scope: open teaching chat with no map, no probe, and no plan. RETIRED with teaching sessions (2026-02).
_Avoid_: scope-less chat kinds
